# TD File Manager - Usage Guide

## Getting Started
 
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Run the application:
   ```bash
   python main.py
   ```

## Features

### you can use Zeus with voice
- **voice libs**:PyAudio, pyttsx3, pywin32


### Connect to nvidia nemotreon
- **with openrouter api-key**: go to https://openrouter.ai/workspaces/default/keys and create a api-key

### open site
- **open site with say or type open site**

### open music
- **open music with say open <musciname> music**
