## 🚀 Installation

### Prerequisites
- Python **3.9** or higher
- pip (Python package manager)

### Step 1: Clone the Repository
```bash
git clone https://github.com/Taha-Azadi/TD-Zeus-Agent
cd TD-Zeus-Agent
```

### Step 2: Install Dependencies
```bash
python install.py
```

### Step 3: Run
```bash
python main.py
```
